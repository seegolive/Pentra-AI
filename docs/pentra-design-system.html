Executive Summary
Pentra AI conducted an adversarial simulation of the wondr.id public attack surface on 15 June 2026 under authorized Rules of Engagement. The assessment identified four confirmed vulnerabilities across the API layer, with two critical findings requiring immediate remediation.
The most severe finding — a time-based blind SQL injection on the product catalog API — allows unauthenticated database extraction from the MSSQL backend. Combined with a JWT algorithm confusion vulnerability that enables authentication bypass without credentials, an attacker could achieve full application compromise in a single session.

MSSQL time-based blind injection via integer parameter — ASP.NET backend
Critical sql_injection CWE-89 Quality: 0.97
Description
Integer parameters passed directly to MSSQL queries without parameterization allow time-based blind SQL injection using WAITFOR DELAY. Common on ASP.NET applications with legacy ADO.NET code patterns.
Payload Pattern
'; WAITFOR DELAY '0:0:5'-- 1'; WAITFOR DELAY '0:0:5'-- ' OR 1=1; WAITFOR DELAY '0:0:5'--
Remediation
Use parameterized queries (SqlCommand with SqlParameter). Enable query execution time limits. Implement WAF rules for SQL keywords in parameter values.
